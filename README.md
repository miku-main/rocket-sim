# Rocket Sim

A 2D model rocket flight simulator built in Godot 4. It uses real motor
trust data and physics to predict how a rocket rlies, and includes a crash
site analysis mode for invetigating failed flights. We're building it to learn rocket physics from scratch,
and we'll validate it against OpenRocket and a real model rocket launch.

## Team
- Gui Sen Zou ([miku-main])
- Jack Lin ([jacklin0401])

## Goals

- Accurate: results validated against OpenRocket and real flight data
- Educational: shows which forces act on the rocket and why
- Fun: rocket builder, challenges, and crash investigation
- 2D first, then 3D once the 2D version is validated

## Status

Phase 0: project setup and learning Godot.

## How to run
1. Install Godot 4 (standard version).
2. Clone this repo
3. In Godot's Porject Manager, click Import and select project.godot.
4. Press F5 to run.
